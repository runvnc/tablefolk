gpu-memory.json and the renderer-string parsing in hardware.js

The GPU memory table is converted from src/detection/gpu-specs.ts of
llmsizer (https://github.com/onepunk/llmsizer), which generates it from
open-gpu-db v1.2.0 (https://github.com/onepunk/open-gpu-db, Apache License
2.0, https://www.apache.org/licenses/LICENSE-2.0; it credits its
TechPowerUp-derived import and vendor corrections). Only each card's name
and memory size are kept. The parsing and lookup in hardware.js are ported
from llmsizer's src/detection/parse-renderer.ts and detect.ts.
