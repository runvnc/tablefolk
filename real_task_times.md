# Real task times

How long tasks really took (wall clock, start to commit), next to the
estimate given beforehand, so later estimates can be calibrated.

Calibration (2026-11-13, four tasks): real time ran 2x to 9x under the
estimate, about 4x under on average. The slowest parts were test-fix loops
with a real model or browser and environment trouble (a full graphics
card), not writing code. Estimate the code at a quarter of the instinct, and
add about 5 minutes per expected browser test round.
